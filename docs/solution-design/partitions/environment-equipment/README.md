# Environment and equipment — solution designs

What a kiao build and deployment put on a machine: delivered resources, runtimes,
and the toolbox that installs and reports them. This partition owns designs spanning
the catalogue, Dashboard's configuration surface and worker's toolbox. Container-
specific detail stays in each container's local `docs/solution-design` (for example
worker's [toolbox design](/operation/worker/docs/solution-design/toolbox.md));
this partition holds only designs spanning those parts.
