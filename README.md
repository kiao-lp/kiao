# KIAO

Kiao is the deliverable that combines DCMS and hybridflow in a Docker image and a `kiao` executable.

- **DCMS**: document and content management. Dashboard provides the file views, [worker](/operation/worker/README.md) provides storage, Git and search.
- **hybridflow**: agentic workflow management. Dashboard provides the boards and conversations, [worker](/operation/worker/README.md) runs the turns, [hybridflow-store](/operation/hybridflow-store/README.md) stores boards, cards, agents and runners in PostgreSQL.

Base components: [Dashboard](/exchange/dashboard/README.md), [worker](/operation/worker/README.md), [hybridflow-store](/operation/hybridflow-store/README.md).
